BASE ALPHA - COMPLETE ENEMY ASSET PACK

Zombie, Horde, Tank, Speedy, Invisible, Sleepy Giant, Dancer. Mystery is a random reveal and has no character assets.

Each folder includes:
- Transparent PNG icons: 64, 128, 256 pixels
- 16 individual 384x384 transparent frames: walk/00.png through 07.png and grab/00.png through 07.png
- 4x4 transparent sprite-sheet.png: first 8 frames walk, next 8 grab
- Infinite looping walk.webp / grab.webp
- Infinite looping APNG walk.png / grab.png

manifest.json lists frame paths and timing. Horde is assembled from three staggered Zombie animation cycles. All artwork was generated using the built-in image generation tool from the approved shabby military-kiddie reference. Prompts specified frowns, ragged clothing, walking poses and reaching/grabbing poses; Dancer uses the Shaggy-inspired pink zombie design.

These are frame-based cartoon loops with some visible pose and drawing variation, not rigged 3D characters. Transparency is included; camera tracking and AR placement belong to the consuming game.

Open preview.html after extracting the entire ZIP to view both states.
