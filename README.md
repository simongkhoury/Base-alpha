# Base Alpha

A pretend-play zombie defense radar for the home. One phone hosts as commander; other phones join with a game code. Includes blaster shot recognition, a walkie-talkie, weapons, inventory, missions and save slots.

Play: https://simongkhoury.github.io/base-alpha/

- `index.html` is the whole game in one file (what GitHub Pages serves).
- `source/` holds the editable code. `python3 source/build.py` rebuilds `source/dist/index.html`; copy it to the repo root to publish.
